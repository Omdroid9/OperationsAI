# Design

<!-- impeccable:design-schema 1 -->

## Direction

Restrained operational marketing aligned with SkyOS workspace: Geist, stone neutrals, contained layouts, photography in rounded frames—not full-bleed splits or experimental display fonts.

## Modes

| Surface | Mode |
|---------|------|
| Marketing | Persuade |
| SkyOS workspace | Operate |

## Typography

Single family on marketing: **Geist Sans** for all roles (hero through labels). **Geist Mono** for IDs and tabular data in workspace only.

## Color (marketing)

| Token | Value |
|-------|-------|
| Background | `#FAFAF9` |
| Surface | `#FFFFFF` |
| Ink | `#1C1917` |
| Muted | `#78716C` |
| Border | `#E7E5E4` |
| Primary action | `#1C1917` (ink button) |

No burnt orange, no multi-font display stacks on marketing until explicitly chosen again.

## Layout

- Hero: contained two-column grid inside max-width; image in bordered frame.
- Sections: whitespace and dividers; no card stacks for lists.

## Anti-patterns

Bento grids, gradient text, glass, fake KPIs, uppercase kickers, loud accent colors.
